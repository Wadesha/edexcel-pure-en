Proof · Mathematical Proof

Edexcel A-Level Pure Mathematics — Topic 1. A proof is a logical argument that shows a statement is true (or false) for every value in a specified set. This topic underpins later Pure work and appears across the Pure papers.

Specification · What students need to learn

  • Understand and use the structure of mathematical proof, including proof by deduction, proof by exhaustion and disproof by counter example.

  • Use correct mathematical language and notation for proof (e.g. integer $\mathbb{Z}$, constant, variable, equation, identity).

  • Distinguish an equation (true for some values, must be solved) from an identity (true for all allowed values, written with $\equiv$).

Notes

What is a proof?

A proof is a sequence of logical steps that shows whether a result is true or not for a specified set of numbers — for example, all integers, or all even numbers. Testing a few values gives *evidence*, not proof.

A standard proof has three parts:

  1. Assumptions — what you are given (e.g. "$n$ is an integer").
  2. Logical steps — each step follows from the previous one using definitions, known identities, or algebraic rules.
  3. Conclusion — state clearly "therefore the result holds for all …".

Key vocabulary: an *equation* is true only for certain values and must be solved (e.g. $x^2=4$); an *identity* is true for every allowed value and is written with $\equiv$ (e.g. $\sin^2\theta+\cos^2\theta\equiv 1$). You can solve an equation, but you cannot "solve" an identity.

Notation in proof

  • $\mathbb{N}$: the set of natural numbers.
  • $\mathbb{Z}$: the set of integers.
  • $\mathbb{Q}$: the set of rational numbers.
  • $\mathbb{R}$: the set of real numbers.
  • LHS and RHS are abbreviations for *left-hand side* and *right-hand side*.

Proof by deduction

Start from general assumptions and use algebra to reach the conclusion. The key trick is usually to write a general term and factorise or rearrange it into a form whose property is obvious.

For example, to show $n^2+n$ is even for any integer $n$:

$$n^2+n=n(n+1)$$

$n$ and $n+1$ are consecutive integers, so one of them is even, and the product is even.

Proof by exhaustion

Check every allowed value — not just a few. This is only practical when the number of cases is finite and small.

  • To show a number is prime, you only need to test factors up to its square root.
  • Exhaustion proves the statement only for the cases you actually list; widen the range and it may fail.

Disproof by counter example

To disprove "the statement holds for all …", you need only find one value that makes it false. That value is a counter example. It must lie inside the claimed set, and you must *verify* that it really breaks the statement.

Helpful places to look: zero, negatives, and (in trigonometry) angles that share the same sine value.

Common pitfalls

  • Treating "three examples work" as a proof.
  • Forgetting to state the range of the variable ($n$ an integer? a real number?).
  • Replacing a real step with "obviously" or "clearly".

Examples (3)

Example 1

Prove that, for any integer $n$, $n^2+3n$ is even.

Solution (click to expand/collapse)

$$n^2+3n=n(n+3)$$

If $n$ is even, write $n=2k$; then $n(n+3)=2k(2k+3)$, which has a factor $2$, so it is even. If $n$ is odd, then $n+3$ is even; write $n+3=2m$; then $n(n+3)=2mn$, which is even. Both cases give an even number, so $n^2+3n$ is even for every integer $n$. $\square$

(Shortcut: $n$ and $n+3$ differ by $3$, an odd number, so they have opposite parity; one is even, hence the product is even.)

Example 2

Prove that, for $x\neq 1$, $\dfrac{x^2-1}{x-1}-x\equiv 1$.

Solution (click to expand/collapse)

$$\frac{x^2-1}{x-1}-x=\frac{(x-1)(x+1)}{x-1}-x=(x+1)-x=1$$

The expression equals $1$ for every $x\neq 1$, so it is an identity. $\square$

Example 3

Statement: "For all real $x$, $(x+2)^2>x^2+4$." Decide whether it is true; if not, give a counter example.

Solution (click to expand/collapse)

$(x+2)^2=x^2+4x+4$. The claim becomes $x^2+4x+4>x^2+4$, i.e. $4x>0$, i.e. $x>0$. So the statement is false for any $x\le 0$. Counter example: $x=0$ gives LHS $=4$, RHS $=4$, and $4>4$ is false. $\square$

Proof by Contradiction

Edexcel A-Level Pure Mathematics — Topic 1 (extension of Proof). Assume the opposite of what you want to prove, then show this assumption leads to an impossible conclusion. The classic applications are the irrationality of $\sqrt{2}$ and the infinity of primes.

Specification · What students need to learn

  • Understand and use proof by contradiction.

  • Apply it to standard results, including the proof that $\sqrt{2}$ is irrational (and, as an extension, that there are infinitely many primes).

  • Support algebraic steps with clear written explanation.

Notes

What is proof by contradiction?

Assume the opposite of the statement you want to prove is true. Then, through a chain of logical steps, show that this assumption leads to something impossible — a contradiction. Because the assumption cannot be true, the original statement must be true.

This method often mixes written sentences with algebra. A typical opening is:

Assume, for contradiction, that …

The contradiction usually takes one of these forms: - a number is forced to be both even and odd; - two integers are shown to share a factor after we assumed they do not; - a quantity is both rational and irrational.

Using prime factorisation

For statements about divisibility or primes, write a number in terms of its prime factors. A clean contradiction often comes from the fact that an integer has a unique prime factorisation.

Examples (3)

Example 1

Prove that $\sqrt{2}$ is irrational.

Solution (click to expand/collapse)

Assume, for contradiction, that $\sqrt{2}$ is rational. Then we can write $$\sqrt{2}=\frac{p}{q}$$ where $p$ and $q$ are integers with no common factor.

Squaring gives $2q^2=p^2$, so $p^2$ is even, and therefore $p$ is even. Write $p=2k$. Then $2q^2=(2k)^2=4k^2$, so $q^2=2k^2$, and $q^2$ is even, so $q$ is even.

But now $p$ and $q$ are both even — they share a factor of $2$, contradicting "no common factor". Therefore $\sqrt{2}$ cannot be rational; it is irrational. $\square$

Example 2

Prove that, if $n^2$ is even, then $n$ must be even.

Solution (click to expand/collapse)

Assume, for contradiction, that $n$ is odd. Then $n=2k+1$ for some integer $k$, and $$n^2=(2k+1)^2=4k^2+4k+1=2(2k^2+2k)+1,$$ which is odd. This contradicts the given fact that $n^2$ is even. Therefore $n$ cannot be odd, so $n$ is even. $\square$

Example 3

Prove that the equation $x^2=2y^2$ has no solution in positive integers.

Solution (click to expand/collapse)

Assume a positive integer solution $(x,y)$ exists. Then $x^2=2y^2$, so $x^2$ is even, and by Example 2 $x$ is even: write $x=2m$. Substituting: $4m^2=2y^2$, so $y^2=2m^2$, so $y^2$ is even, and $y$ is even. Then $x$ and $y$ are both even, so they share a factor of $2$ — contradicting that we may take them with no common factor. Therefore no positive integer solution exists. $\square$

Indices & Surds

Edexcel A-Level Pure Mathematics — Topic 2. Index laws let you simplify powers; surds let you work with exact irrational roots. Both appear throughout Pure and are tested on their own and inside harder algebra.

Specification · What students need to learn

  • Use and apply the laws of indices to simplify and manipulate expressions involving powers.

  • Change the base of a term to simplify expressions with different bases.

  • Understand a surd as an irrational root and simplify surd expressions.

  • Rationalise the denominator of a fraction involving surds.

Notes

Laws of indices

Index laws let you simplify and manipulate expressions involving powers. Note: "index" is the singular, "indices" the plural. The laws only work for terms that share the same base.

  • $a^{x}\times a^{y}=a^{x+y}$
  • $a^{x}\div a^{y}=a^{x-y}$
  • $(a^{x})^{y}=a^{x y}$

Changing the base. When terms have different bases, rewrite one base to match the other. For example, $9^{4}=(3^{2})^{4}=3^{8}$, so $9^{4}\div 3^{7}=3^{8}\div 3^{7}=3^{1}=3$.

Manipulating surds

A surd is an irrational root — for instance $\sqrt{n}$ where $n$ is a positive integer that is not a perfect square. Surds are examples of irrational numbers.

  • $\sqrt{a}\,\sqrt{b}=\sqrt{ab}$
  • $\dfrac{\sqrt{a}}{\sqrt{b}}=\sqrt{\dfrac{a}{b}}$

When simplifying, look for square factors: $\sqrt{12}=\sqrt{4\times3}=2\sqrt{3}$. You can collect like surds just as you collect like letters: $3\sqrt{2}+5\sqrt{2}=8\sqrt{2}$. But do not confuse this with the multiplication/division rules — you cannot add "under the surd", since $\sqrt{2}+\sqrt{3}\neq\sqrt{5}$.

Leaving an answer in exact surd form is often required; it avoids the rounding error you would get from carrying an approximation like $7.07$ forward into later working.

Rationalising the denominator

Rationalising turns a fraction with a surd in its denominator into an equal fraction whose denominator is rational (usually an integer), with any surd moved up to the numerator.

  • Single surd: multiply top and bottom by that surd — $\dfrac{1}{\sqrt{b}}=\dfrac{\sqrt{b}}{b}$.
  • Binomial with a surd: multiply top and bottom by the conjugate — $\dfrac{1}{a+\sqrt{b}}=\dfrac{a-\sqrt{b}}{a^{2}-b}$.

Note: "in the form $p+q\sqrt{3}$ where $p$ and $q$ are rational" does not mean $p$ and $q$ must be integers or positive — rationals include fractions and negatives.

Examples (3)

Example 1

Simplify $8^{5}\times 2^{-3}\div 4^{2}$.

Solution (click to expand/collapse)

Rewrite every base as $2$: $8=2^{3}$ and $4=2^{2}$. $$8^{5}\times 2^{-3}\div 4^{2}=(2^{3})^{5}\times 2^{-3}\div(2^{2})^{2}=2^{15}\times 2^{-3}\div 2^{4}=2^{15-3-4}=2^{8}=256.$$

Example 2

Simplify $\sqrt{50}+3\sqrt{8}-2\sqrt{18}$.

Solution (click to expand/collapse)

$$\sqrt{50}=\sqrt{25\times2}=5\sqrt{2},\qquad 3\sqrt{8}=3\sqrt{4\times2}=6\sqrt{2},\qquad 2\sqrt{18}=2\sqrt{9\times2}=6\sqrt{2}.$$ So $5\sqrt{2}+6\sqrt{2}-6\sqrt{2}=5\sqrt{2}$.

Example 3

Write $\dfrac{5}{2+\sqrt{3}}$ in the form $a+b\sqrt{3}$ with $a,b$ rational.

Solution (click to expand/collapse)

Multiply numerator and denominator by the conjugate $2-\sqrt{3}$: $$\frac{5}{2+\sqrt{3}}=\frac{5(2-\sqrt{3})}{(2+\sqrt{3})(2-\sqrt{3})}=\frac{10-5\sqrt{3}}{4-3}=10-5\sqrt{3}.$$ So $a=10$ and $b=-5$.

Quadratics

Edexcel A-Level Pure Mathematics — Topic 3. Quadratics cover the graph of $y=ax^2+bx+c$, the discriminant, completing the square, solving by factorising / formula / square-completion, and "hidden" quadratics solved by substitution.

Specification · What students need to learn

  • Sketch quadratic graphs and find their intercepts and turning point.

  • Use the discriminant $b^2-4ac$ to determine the number of real roots and to solve related inequalities.

  • Complete the square and use it to locate the turning point.

  • Solve quadratic equations by factorising, completing the square, and the quadratic formula.

  • Solve hidden quadratics using a substitution.

Notes

Quadratic graphs

The general equation is $y=ax^2+bx+c$. Its shape is a parabola. If $a>0$ it opens upward $(\cup)$; if $a<0$ it opens downward $(\cap)$.

From the equation you should be able to: - sketch the graph, possibly after rearranging into $y=ax^2+bx+c$; - read off the axis intercepts; - factorise (when possible) to find the roots; - find the coordinates of the turning point (maximum or minimum).

The discriminant

The discriminant is the part under the square root in the quadratic formula: $b^2-4ac$. It is often written $\Delta$.

  • $\Delta>0$: the graph crosses the $x$-axis twice → two distinct real roots.
  • $\Delta=0$: the graph touches the $x$-axis once → one repeated real root.
  • $\Delta<0$: the graph does not cross the $x$-axis → no real roots.

When a question mentions only "real roots", it means distinct or repeated (not complex), so you solve $\Delta\ge 0$. For inequalities, sketch the quadratic and decide whether you need the region above or below zero.

Completing the square

This rewrites $y=ax^2+bx+c$ as $y=a(x+p)^2+q$.

  • When $a=1$: $p=\dfrac{b}{2}$ and $q=c-p^2$.
  • When $a\neq 1$: factor $a$ out of the $x^2$ and $x$ terms first, then proceed.

It is useful for finding the turning point $(-p,\,q)$, for building a quadratic from its turning point, and for proving results that rely on a squared term always being $\ge 0$.

Solving quadratic equations

First write the equation as $ax^2+bx+c=0$. The three methods are factorising, completing the square, and the quadratic formula. Factorising is fastest but does not always work; the other two always work. A calculator may give the roots, but method marks still matter.

Hidden quadratics

A hidden quadratic is a quadratic in a function $f(x)$: $a[f(x)]^2+b[f(x)]+c=0$. Substitute $u=f(x)$, solve the ordinary quadratic for $u$, then substitute back. For example, $\sin^2x+2\sin x-3=0$ is the hidden quadratic $u^2+2u-3=0$ with $u=\sin x$.

Examples (3)

Example 1

Find the values of $k$ for which $x^2+kx+4=0$ has exactly one real root.

Solution (click to expand/collapse)

Exactly one real root means $\Delta=0$: $$k^2-4(1)(4)=0\quad\Rightarrow\quad k^2=16\quad\Rightarrow\quad k=\pm 4.$$

Example 2

Write $x^2-6x+2$ as $(x+p)^2+q$ and state its turning point.

Solution (click to expand/collapse)

$p=-\dfrac{6}{2}=-3$; $q=2-(-3)^2=2-9=-7$. So $$x^2-6x+2=(x-3)^2-7.$$ The turning point is $(3,-7)$, a minimum because $a=1>0$.

Example 3

Solve $\sin^2x+2\sin x-3=0$ for $0\le x\le 2\pi$.

Solution (click to expand/collapse)

Let $u=\sin x$. Then $u^2+2u-3=0=(u+3)(u-1)$, so $u=-3$ or $u=1$. $\sin x=-3$ is impossible (sine lies in $[-1,1]$). $\sin x=1$ gives $x=\dfrac{\pi}{2}$ in the range. Solution: $x=\dfrac{\pi}{2}$.

Simultaneous Equations

Edexcel A-Level Pure Mathematics — Topic 4. Simultaneous equations involve more than one equation in more than one unknown. Linear pairs are solved by elimination or substitution; a quadratic paired with a linear equation is solved by substitution only.

Specification · What students need to learn

  • Solve linear simultaneous equations using elimination and substitution.

  • Solve quadratic simultaneous equations (one quadratic, one linear) using substitution.

Notes

Linear simultaneous equations

You have more than one equation in more than one unknown. An equation is linear when no unknown is raised to a power other than $1$. Solving the pair means finding values that make both equations true at the same time. A pair of linear equations graphs as two straight lines that cross (when a solution exists).

Solving linear equations by elimination

  1. Multiply one (or both) equations by a constant so the coefficients of one unknown match.
  2. If the matching coefficients have the same sign, subtract the equations; if opposite signs, add them.
  3. Solve the new equation for one unknown.
  4. Substitute that value into an original equation to find the other unknown.
  5. Check by substituting both values into the equation you did not use in step 4.

Mishandling minus signs is the single most common error here — never skip the checking step.

Solving linear equations by substitution

  1. Rearrange one equation to make one unknown the subject.
  2. Substitute that expression into the other equation.
  3. Solve for the remaining unknown.
  4. Substitute back to find the first unknown.
  5. Check using the equation you rearranged in step 1.

Either method always works for a linear pair; substitution is also the one you need for quadratic pairs.

Quadratic simultaneous equations

One equation is quadratic, the other linear. You must use substitution (elimination will not work):

  1. Rearrange the linear equation to make one unknown the subject.
  2. Substitute into the quadratic equation.
  3. Solve the resulting quadratic (usually two values).
  4. Substitute each value back to find the matching other unknown.
  5. Check each pair in the original quadratic equation.

There are usually two solution pairs, but there can be one or none.

Examples (3)

Example 1

Solve $x+y=10$ and $2x-y=5$.

Solution (click to expand/collapse)

Add the equations to eliminate $y$: $$(x+y)+(2x-y)=10+5\quad\Rightarrow\quad 3x=15\quad\Rightarrow\quad x=5.$$ Substitute into $x+y=10$: $5+y=10$ ⇒ $y=5$. Check in $2x-y=5$: $2(5)-5=5$ ✓. Solution: $x=5$, $y=5$.

Example 2

Solve $x=2y+1$ and $x+y=7$.

Solution (click to expand/collapse)

Substitute $x=2y+1$ into $x+y=7$: $$(2y+1)+y=7\quad\Rightarrow\quad 3y=6\quad\Rightarrow\quad y=2.$$ Then $x=2(2)+1=5$. Check in $x+y=7$: $5+2=7$ ✓. Solution: $x=5$, $y=2$.

Example 3

Solve $y=x^2-4$ and $y=3x$.

Solution (click to expand/collapse)

Substitute $y=3x$ into the quadratic: $$3x=x^2-4\quad\Rightarrow\quad x^2-3x-4=0\quad\Rightarrow\quad (x-4)(x+1)=0.$$ So $x=4$ or $x=-1$. If $x=4$, $y=12$; if $x=-1$, $y=-3$. Check each in $y=x^2-4$: $12=16-4$ ✓, and $-3=1-4$ ✓. Solutions: $(4,12)$ and $(-1,-3)$.
